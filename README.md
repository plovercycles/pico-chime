Raspberry Pi Pico 活用 オフライン定時チャイムシステム設計書
1. システム概要
本システムは、インターネット環境やWi-Fi接続を必要とせず、リアルタイムクロック（RTC）とオフラインマイコンを用いて、設定された平日の定刻に自動でチャイム音（MP3）を再生するスタンドアロン型の定時チャイムシステムです。シンプルで低コストな構成ながら、高い時間精度と安定した連続稼働を実現します。
2. ハードウェア仕様
本システムを構成する主要なハードウェア部品および選定仕様は以下の通りです。
項目	選定仕様	備考・補足
メイン制御マイコン	Raspberry Pi Pico WH (ピン実装済み)	半田付け不要でブレッドボードや配線が容易なモデル
リアルタイムクロック	DS3231 時計モジュール	高精度、CR2032ボタン電池バックアップ付き（停電時も時間保持）

3. ソフトウェア・動作仕様
システムを制御するプログラムの言語、時刻管理、および鳴動スケジュールは以下の仕様で実装します。
•	使用言語：MicroPythonを採用し、直感的でメンテナンス性の高いコード構成とする。
•	時刻管理：初回起動時にPC（Thonny等の開発環境）から手動で正確な時刻を書き込む。以降はDS3231モジュールから常時時刻を取得し、必要に応じた微調整もPC経由で手動実施する。
•	鳴動スケジュール：平日（月曜〜金曜）の指定時刻にのみ鳴動させ、土曜・日曜は鳴らさない設定とする。音源は1種類のMP3ファイル（ウェストミンスターの鐘など）を使用する。
•	制御ロジック：プログラム内で毎分（または毎秒）現在時刻をチェックし、「平日 かつ 指定時刻」に合致した場合にDFPlayer Miniへ再生コマンドを送信する。同一分内での重複鳴動を防ぐインターバル処理を組み込む。
4. 拡張・メンテナンス性
将来的な機能変更および運用保守に関する方針は以下の通りです。
•	音声出力のアップグレード：初期段階ではアンプ非搭載の小型スピーカー直結で運用するが、将来的に大きな音量や高音質が必要になった際は、DFPlayer Miniの出力先をアンプ内蔵スピーカーに変更することで容易に拡張可能とする。
•	時刻のズレへの対応：採用しているDS3231モジュールは温度補正機能付きで極めて高精度なため、年間を通しても大きな時刻ズレは発生しない。季節の変わり目等で微調整が必要になった場合は、USB経由でPCを接続して手動で再同期を行う。
